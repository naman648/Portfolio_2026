# Naman Verma Portfolio

Premium dark + glass editorial portfolio built with Next.js, TypeScript, Tailwind CSS, Motion and Lenis.

## Current build
- Responsive navbar with scroll glass state
- Mobile navigation overlay
- Hero section
- Animated data-flow visual
- Initial page anchors for Projects, Experience, About and Contact

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000
